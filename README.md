# 🏪 Smart Shop Manager

A desktop-based shop management application built with Python and Tkinter.

Smart Shop Manager helps small businesses manage products, inventory, sales, expenses and profit from one simple application.

## 🚀 Features

- 📊 Business Dashboard
- ➕ Add Products
- ✏️ Edit Products
- 📦 Restock Products
- 🗑️ Delete Products
- 🛒 Record Sales
- 🧾 Customer Sales Receipts
- 📋 Sales History
- 💸 Expense Tracking
- 📈 Profit Calculation
- 🔍 Product Search
- ⚠️ Low Stock Alerts
- 📊 Sales Analytics
- 📄 CSV Reports
- 💾 Persistent JSON Data Storage

## 🛠️ Technologies Used

- Python
- Tkinter
- JSON
- CSV
- Git
- GitHub

## 💻 Requirements

- Python 3.x
- Windows / Linux / macOS

No external Python packages are required.
